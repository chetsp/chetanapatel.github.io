# Technology marks

SVG marks are bundled locally to avoid third-party image dependencies and support GitHub Pages subpaths.

- Simple Icons: https://github.com/simple-icons/simple-icons/tree/develop/icons — Python, Go, Claude, Gemini, LangGraph, Pydantic, MCP, Google, TypeScript, React, Next.js, FastAPI, Node.js, Tailwind CSS, Docker, Kubernetes, Helm, PostgreSQL, MySQL, OpenTelemetry, Grafana, Kafka, and Google Cloud.
- Devicon: https://github.com/devicons/devicon/tree/master/icons — Java, AWS, C++, Spring, and GitHub Actions.

PydanticAI uses the Pydantic project-family mark. Google ADK uses Google's owner mark. RAG, evaluations, distributed scheduling, and generic SQL are techniques rather than brands; their tiles use Lucide semantic icons. Devicon marks are normalized to monochrome; CSS inverts monochrome image assets in dark mode. Organization logos retain their colors on a white badge surface.

# Technology marks

SVG files are served locally. Sources:

- Devicon original-color assets: https://github.com/devicons/devicon/tree/master/icons — Codex, Python, Go, Java, TypeScript, React, Next.js, FastAPI, Node.js, Tailwind CSS, Docker, Kubernetes, Helm, PostgreSQL, MySQL, OpenTelemetry, Grafana, AWS, Google Cloud, Google, C++, and GitHub Actions.
- Simple Icons: https://github.com/simple-icons/simple-icons/tree/develop — Claude, LangGraph, Pydantic, MCP, Kafka, and Spring. Simple Icons paths use their published brand colors; Spring retains its original Devicon color mark.
- Gemini color-gradient mark: https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/gemini-color.svg

Google ADK and PydanticAI use their owner/project-family marks. RAG, evaluations, distributed scheduling, and generic SQL use Lucide symbols. No image inversion is applied; white badge surfaces preserve visibility of black brand marks in either theme.
